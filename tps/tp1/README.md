# TP1 — Web scraping et API

Ce dossier contient les deux notebooks réalisés dans le cadre du premier travail pratique du cours de Traitement automatique de corpus.

## Fichiers

- `tp1_scraping_camille.ipynb` : récupération des 51 liens PDF publiés sur la page CAMille, téléchargement automatique des fichiers, contrôle des téléchargements et exploration de cinq documents datés de 1836 à 1950.
- `tp1_api_camille.ipynb` : interrogation de l’API Nominatim d’OpenStreetMap pour associer des coordonnées géographiques à cinq lieux relevés dans l’échantillon du corpus.

## Données

Les PDF téléchargés sont conservés localement dans le dossier `pdf_camille`. Ils ne sont pas publiés dans le dépôt, puisque le notebook permet de les récupérer automatiquement depuis leur source.
